Namaz Tracker — Android PWA

Состав: index.html, manifest.webmanifest, sw.js и icons/. Исходный ключ localStorage namazTracker_v1 сохранён; существующие отметки и долги переносятся автоматически. Для расписания и журнала однократного начисления используются дополнительные ключи localStorage.

Публикация на GitHub Pages:
1. Сделайте резервную копию действующего репозитория.
2. Замените файлы приложения содержимым этой папки, сохранив относительные пути и каталог icons.
3. Отправьте изменения в ветку, из которой GitHub Pages публикует сайт.
4. Дождитесь успешного завершения публикации и откройте HTTPS-ссылку.
5. На Android откройте ссылку в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Время расписания используется без часового сдвига, как оно показано на NamazTimes.kz для Алматы. Для вычисления момента наступления намаза оно трактуется как местное время Алматы UTC+5.

Ограничения: пока приложение открыто, проверка выполняется каждую минуту. При открытии или возвращении сверяются сохранённые расписания, а начисление защищено от повторов. API NamazTimes.kz предоставляет расписание на один день, поэтому если приложение закрыто несколько дней и расписания этих дат не сохранены, восстановить все пропущенные дни автоматически не получится. Android также может приостановить PWA в фоне, поэтому точная проверка при закрытом приложении не гарантируется.
